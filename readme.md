# 狭山市（xx地区）リアルタイム水害リスク判定システム

本システムは、埼玉県狭山市xx地区周辺を対象に、河川水位（外水）および雨量・浸水ハザード（内水）を複合的に評価し、リアルタイムで警戒レベルを出力する防災支援システムです。

- [x] TypeScript型定義 (`src/types/index.ts`) の作成
- [!] **河川水位取得 (`src/ingestion/riverApiClient.ts`) - 検証中**

#### 【検証記録】国土交通省「川の防災情報」からのデータ取得における検証と課題
* **アプローチ1: HTTPクライアント（Axios）による内部APIダイレクト呼び出し**
  * **結果:** 失敗
  * **原因:** サイト側（SPA構造）でリダイレクト制限およびWAF/Bot対策が施されており、通信ヘッダー（User-Agent, Referer等）を模擬してもJSONではなくトップページのHTMLが返却される。
* **アプローチ2: ヘッドウエイ（Puppeteer）によるDOMレンダリングスクレイピング**
  * **結果:** 失敗（不安定）
  * **原因:** SPA（Vue.js）の非同期描画タイミングと検索画面への強制リダイレクト仕様により、要素の抽出（`stage` 水位数値）が安定しない。
* **今後の方針:**
  * システム全体の骨組み（GIS空間判定・リスク評価ロジック）を先行して完成させるため、`riverApiClient.ts` は一旦**モックデータ（ダミー数値返却）**を返す構成に切り替え。
  * システム基盤完成後、Yahoo!天気等の安定した別データソースへの変更、または公式オープンデータAPI（気象庁XML等）の統合を実施予定。
